# 広告×ボタン早押し 10 ROUND RTA (Close the Ad! Speedrun)

全10問の凶悪広告を素早く閉じろ！誤クリックは +3.00s ペナルティのスピードランWebゲームです。

## 特徴
- **全10ラウンドの多彩な広告ギミック**: 極小×ボタン、偽の×マーク、保護色、カウントダウン待機、カーソル逃亡、はみ出しボタン、2段階確認など
- **LiveSplit風 スプリット＆タイマー**: リアルタイムで区間タイムと総合タイムを計測・比較
- **IndexedDB 連動**: 
  - 走者ランキング（リーダーボード）
  - 各ラウンドの統計・分析ダッシュボード
  - 自己ベスト（PB）・区間最速（ゴールドスプリット）の自動集計

## 起動方法
ブラウザで直接 `index.html` を開くか、またはローカルサーバーを起動してアクセスしてください。

### PowerShellでの起動例
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
起動後、ブラウザで [http://localhost:8080/](http://localhost:8080/) を開きます。
